- `curriculum/progress.md` = إحنا وصلنا فين في كل صف. البوستات العلمية (معلومة / شرح / سؤال امتحان) بتتكتب **من الدرس اللي وصلناله أو اللي قبله بس**، عمرها ما تسبق الطلبة.

## الترتيب
