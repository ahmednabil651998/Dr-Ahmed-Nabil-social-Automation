# Ahmed Nabil Page Automation

ريبو مركزي لتعليمات وبرومبتس أتمتة صفحة د. أحمد نبيل (فيسبوك) — بوستات يومية، ريلز، ورد على الكومنتات.

## المحتوى

- `instructions/` — تعليمات كل تاسك (إزاي يتكتب البوست، شكل التصميم، قواعد الهاشتاجات...)
- `prompts/` — البرومبتس الجاهزة اللي تُستخدم مع Claude لتوليد المحتوى
- `docs/` — أي توثيق إضافي (handoff docs، IDs، ملاحظات، سجل الأعطال)
- `content/` — نسخة احتياطية من محتوى تاب `Posts` في الشيت (`posts.csv`)، بتتحدّث مع كل بوست أو فكرة جديدة. لو الشيت اتمسح نرجّعه منها
- `docs/post-ideas-playbook.md` — دليل أفكار البوستات: الأنواع، الشكل المتكرر، إزاي نبني فكرة جديدة، وسجل الأفكار. وروتين إضافة فكرة جديدة في `instructions/idea-intake.md`
- `apps-script/` — نسخة من كود Google Apps Script الفعلي (Code.gs، و Reels.gs للريلز) المركّب على المشروع المربوط بالجدول، كنسخة احتياطية/مرجعية. مفيهوش أي توكنز أو أسرار؛ دي بتتخزن في Script Properties جوه Apps Script نفسه فقط

## السياق الحالي

الأتمتة شغالة دلوقتي عن طريق Google Apps Script + Sheet + Telegram bot (@DrAhmedNabil_Posts_bot)، بدون الحاجة لتشغيل أي جهاز. الريبو ده الهدف منه يكون مصدر واحد للتعليمات والبرومبتس بدل ما تكون متوزعة بين الشات والشيت، تمهيدًا لو احتجنا بعدين نشغّل جزء من الشغل عن طريق Claude Scheduled Tasks بدل Apps Script.
