# Ahmed Nabil Page Automation

ريبو مركزي لتعليمات وبرومبتس أتمتة صفحة د. أحمد نبيل (فيسبوك) — بوستات يومية، ريلز، ورد على الكومنتات.

## المحتوى

- `instructions/` — تعليمات كل تاسك (إزاي يتكتب البوست، شكل التصميم، قواعد الهاشتاجات...)
- `prompts/` — البرومبتس الجاهزة اللي تُستخدم مع Claude لتوليد المحتوى
- `docs/` — أي توثيق إضافي (handoff docs، IDs، ملاحظات)

## السياق الحالي

الأتمتة شغالة دلوقتي عن طريق Google Apps Script + Sheet + Telegram bot (@DrAhmedNabil_Posts_bot)، بدون الحاجة لتشغيل أي جهاز. الريبو ده الهدف منه يكون مصدر واحد للتعليمات والبرومبتس بدل ما تكون متوزعة بين الشات والشيت، تمهيدًا لو احتجنا بعدين نشغّل جزء من الشغل عن طريق Claude Scheduled Tasks بدل Apps Script.
