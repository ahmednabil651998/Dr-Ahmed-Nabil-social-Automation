# خطة أتمتة الريلز (فيسبوك + يوتيوب، وتيك توك بعدين)

> الحالة: **خطة للمراجعة**، لسه متنفذتش. محدش يبدأ تنفيذ قبل موافقة د. أحمد سليم.

## الهدف

الريل يمشي بنفس طريقة البوست اليومي اللي شغالة دلوقتي:
الشيت ← يتبعت على Telegram للموافقة ← تدوس "انشر" ← يتنشر على فيسبوك ويوتيوب ← يوصلك إشعار بالنتيجة.

## الشروط الأساسية

- **مجاني بالكامل:** مفيش أي خدمة مدفوعة ولا اشتراك.
- **من غير جهاز ولا سيرفر:** كله جوه نفس مشروع Google Apps Script المربوط بالشيت.
- **مش هننسخ ريبو كامل:** هناخد بس **الفكرة** من ريبو `Jee-vim/clip-pipe` (رفع الريل بالـ API الرسمي + إشعار Telegram لكل منصة)، ونكتبها بنفسنا جوه `Code.gs`.
- **البوست اليومي ما يتأثرش:** الكود الجديد في دوال منفصلة، ومنطق البوست اليومي ما يتغيرش.
- **مفيش توكنز في الريبو:** كل المفاتيح في Script Properties بس، زي دلوقتي.

## اللي هيتعمل في الشيت

تاب جديد اسمه `Reels`، كل صف = ريل واحد:

| العمود | المحتوى |
|---|---|
| رقم | رقم الريل |
| التاريخ | يوم النشر (yyyy-MM-dd) |
| الحالة | جاهز / اتبعت للموافقة / تمت الموافقة / اتنشر / فشل جزئي |
| العنوان | عنوان قصير (بيستخدم كعنوان يوتيوب، أقصى حد 100 حرف) |
| الكابشن | نص الريل + الهاشتاجات الثابتة |
| ملف الفيديو | ID ملف الفيديو على Drive |
| رابط فيسبوك | بيتملى لوحده بعد النشر |
| رابط يوتيوب | بيتملى لوحده بعد النشر |
| ملاحظات | للخطأ لو حصل |

مكان الفيديوهات: فولدر جديد على Drive اسمه `Reels` جوه نفس حساب الشيت.

## الفلو

1. **مرة في اليوم** في ميعاد بنحدده (مقترح 8 بالليل، منفصل عن بوست 5 العصر) الكود ياخد أول ريل حالته "جاهز".
2. **يبعته على Telegram** كفيديو، ومعاه الكابشن وزراير: ✅ انشر / ✏️ تعديل الكابشن / ⏭ أجّل لبكرة. (نفس زراير البوست بالظبط.)
3. **لما تدوس "انشر"** يتنشر على فيسبوك ريلز الأول، وبعده يوتيوب Shorts.
4. **إشعار منفصل لكل منصة:** "✅ فيسبوك اتنشر + الرابط" و"✅ يوتيوب اتنشر + الرابط"، أو "❌ يوتيوب فشل + السبب".
5. **لو منصة نجحت والتانية فشلت** الحالة تبقى "فشل جزئي"، ويبقى فيه أمر في Telegram يعيد المنصة اللي فشلت بس، عشان الريل ما يتنشرش مرتين على المنصة اللي نجحت.

## التنفيذ على كل منصة

### فيسبوك ريلز (مجاني)
- نفس توكن الصفحة الدائم الموجود دلوقتي، ومن غير صلاحيات جديدة غالبًا (هنتأكد في التجربة).
- الرفع على 3 خطوات حسب Reels Publishing API الرسمي: `start` ← رفع الملف ← `finish` مع الوصف ونشره.

### يوتيوب Shorts (مجاني)
- نشغّل خدمة YouTube Data API جوه Apps Script (Advanced Service)، وده ما بيحتاجش سيرفر.
- الحد المجاني حوالي **6 فيديوهات في اليوم**، وده أكتر من كفاية.
- لازم الحساب اللي شغال بيه السكريبت يكون عنده صلاحية على قناة اليوتيوب.
- **نقطة لازم نختبرها الأول:** يوتيوب ممكن يخلي الفيديوهات المرفوعة من مشروع API لسه ما اتراجعش تتنشر **Private**. المراجعة نفسها ببلاش (فورم بنقدمه ليوتيوب). لو طلعت مشكلة، أول ريلز هتخليها Public بإيدك لحد ما المراجعة تخلص.

### تيك توك (مؤجل)
- الـ API مجاني، بس لحد ما تيك توك يوافق على التطبيق بعد المراجعة، الفيديوهات بتتنشر **Private** بس.
- كمان محتاج صفحة Privacy Policy ورابط للتطبيق.
- **القرار:** نأجله لمرحلة تالتة، وتيك توك يتنشر يدوي لحد كده.

## الحدود اللي لازم نلتزم بيها

- **حجم الريل أقل من حوالي 50 ميجا** (حد Apps Script وحد إرسال الفيديو من بوت Telegram). ريل دقيقة بجودة 1080×1920 عادة بيبقى أقل من كده.
- **مدة الريل:** أقل من 90 ثانية عشان يتحسب ريل على فيسبوك، وأقل من 3 دقايق عشان يتحسب Short على يوتيوب.
- **وقت التنفيذ:** Apps Script بيقف بعد 6 دقايق. عشان كده كل منصة ليها خطوة لوحدها، ولو الرفع اتأخر بنكمّل في الدقيقة اللي بعدها.
