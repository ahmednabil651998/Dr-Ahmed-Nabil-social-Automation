# مستني جهاز: اللي يتعمل أول ما كمبيوتر أو Chrome يتوصل

> اتكتب 2026-11-18. أي جلسة Claude جاية تبدأ من هنا لو اتقالها «الجهاز اتوصل» أو «كمّل التركيب».
> شرط البداية: Claude in Chrome متصل، أو فولدر على الكمبيوتر متصل بـ Remote Control. ومحرر Apps Script مفتوح بحساب `651999`.

## قبل أي حاجة
- [ ] **نسخة احتياطية:** File → Make a copy لمشروع Apps Script، أو انسخ كل الملفات الحالية لملف على الجهاز.
- [ ] **التأكد إن الكود الشغال لسه هو نفسه** اللي في فرع `feature/system-upgrade`: قارن طول `Code.gs` و`Reels.gs` بالفرع. لو مختلفين، **وقّف** واسأل د. أحمد، لأن ملفات `apps-script/next/` مبنية على النسخة دي.

## 1) سبب إن بوست 3 ما اتبعتش يوم 2026-11-17
- [ ] **Triggers:** لازم يكون فيه `dailyJob` (كل ساعة) و`pollTelegram` (كل دقيقة). لو ناقص، شغّل «3) تشغيل النظام» من قايمة «إعداد النشر» في الشيت.
- [ ] **Executions:** فلتر على `dailyJob` حوالي الساعة 5 العصر يوم 2026-11-17. سجّل الخطأ لو موجود في `docs/incidents.md`.

## 2) تركيب الملفات (من `apps-script/next/`)
- [ ] ملف جديد `Learning` ← `apps-script/next/Learning.gs`.
- [ ] ملف جديد `Snapshots` ← `apps-script/next/Snapshots.gs`.
- [ ] `Code.gs` ← استبدال كامل بـ `apps-script/next/Code.gs`.
- [ ] `Reels.gs` ← استبدال كامل بـ `apps-script/next/Reels.gs`.
- [ ] Save ← مفيش خط أحمر، وطول كل ملف بعد Reload مطابق للريبو.
- [ ] لو ظهر «Authorization required»: نفس الحل اللي في `docs/incidents.md` (2026-11-17، تركيب الإضافات).
- **ما تركّبش** `Analytics.gs` بتاع طلب الدمج 11 (A1)، لأنه هيتعارض مع `Analytics.gs` الشغال.
- ما تلمسش أي ملف تاني، ولا Triggers، ولا Script Properties.

## 3) التجربة بعد التركيب
- [ ] **التعديلات:** على تيليجرام دوس «✏️ تعديل» على بوست مستني، وابعت كابشن. لازم صف يظهر في تاب `Edits`.
- [ ] **اللقطات:** من المحرر شغّل `snapshotsNow`. لازم توصل رسالة «📸 لقطات الأرقام: اتكتب X صف».
  - لو تاب `Analytics` فاضي، شغّل `analyticsNow` الأول.
  - بص على عمود الوصول في `Snapshots`: لو فاضي، يبقى `post_total_media_view_unique` مش شغال مع التوكن. سجّل ده وجرّب `post_media_view` في `FB_VIEWS_METRIC`.
- [ ] **المحاولة المتأخرة:** مفيش تجربة يدوية. بتبان لوحدها لو إرسال الساعة 5 ما حصلش.

## 4) بعد ما كله يشتغل
- [ ] تحديث `apps-script/` في `main` بالكود الشغال (فرع `feature/system-upgrade` + ملفات `apps-script/next/`)، عشان الريبو يبقى نسخة طبق الأصل.
- [ ] تسجيل التركيب في `docs/incidents.md`، وتحديث الحالة في `README.md`.

## إنستجرام (محتاج د. أحمد على الكمبيوتر)
- [ ] Generate Access Token + لصق التوكن و App Secret في «ربط فيسبوك»، وبعدها «ربط إنستجرام» والتفعيل. الخطوات في `docs/instagram-status.md`.
